# 安装、更新与排错

公开版本为 [0.2.0-beta.1 / Build 17](https://github.com/double-u-zw/MacMouseGesture/releases/tag/v0.2.0-beta.1)。仓库当前开发版为 `0.2.0-beta.1-dev / Build 33`，包含新增映射功能；开发版的检查不等同于公开包验收。已验证范围见[兼容性矩阵](compatibility-matrix.md)。

## 安装与权限

1. 从官方 Release 下载 DMG 与同版本 SHA256SUMS。需要校验时，在下载目录运行 `shasum -a 256 -c SHA256SUMS`；校验不能代替可信来源或 Apple 公证。
2. 打开 DMG，将 MacMouseGesture.app 拖到“应用程序”，推出 DMG，再启动已安装的 App。它是菜单栏应用，关闭设置窗口后仍运行。
3. 按设置向导开启当前 App 的“辅助功能”权限，测试鼠标按钮及连续手势。常见侧键按住拖动：左右切换桌面，上拖调度中心，下拖应用 Exposé。

现有公开包使用本地签名，没有 Developer ID 分发签名或 Apple 公证。确认来源和完整性后，按 [Apple 打开 App 指南](https://support.apple.com/102445)处理系统提示；若提示恶意软件、文件损坏或组织策略不允许打开，请停止并反馈。安装无需导入开发证书或钥匙串，也无需关闭系统安全保护。

辅助功能用于捕获配置输入和执行动作。输入监控用于可选鼠标观察及兼容诊断，未设为基本手势启动门槛；干净用户的最小权限组合仍待完整实测。权限页深链接失效时，手动进入“系统设置 → 隐私与安全性”，找到对应权限。

## 当前开发版的配置

主界面使用“鼠标输入 / 操作方式 / 执行动作”三列。添加或编辑时可录制中键、侧键及额外按钮，并选择短按、长按、按住滚轮等操作；左、右主键受保护。修饰键支持 Command、Option、Control、Shift。

主表动作选择器直接保存选择；添加、编辑弹窗在保存时才写入，取消保留原配置。连续拖动以“触控板式手势”分组，详情控制各方向和全局参数。恢复默认参数不覆盖映射。停用整个手势组后的方向恢复、删除撤销仅在本次会话有效。未知设备按钮、动作兼容限制及快捷键录制限制见[兼容性矩阵](compatibility-matrix.md)。

## 更新与回退

先退出当前实例，将新 App 放到相同位置后打开；没有自动更新。身份或证书变化可能需要重新授权。永久 Bundle ID 为 `io.github.double-u-zw.macmousegesture`。

从旧 `local.macmousegesture.poc` 版本更新时，已知手势配置和首次设置完成状态按缺失值导入，旧偏好域保留。旧版开启登录启动时，先在旧 App 关闭，再更新，并在新 App 按需开启；系统可能要求批准。不要同时运行多个版本。

开发映射包含修饰键、长按或滚轮时采用较新文档格式。旧版本不能完整读取或编辑这些配置；回退前先备份当前偏好，使用可信旧包及对应配置备份。退出新版后再运行旧版，不删除权限记录来强制解决身份差异。

## 排错与反馈

- 没有菜单栏图标：检查 App 是否已退出或被系统阻止；另一副本已运行时，新副本会激活现有实例或退出。
- 需要授权：在设置中的“权限检查”启用当前 App 的辅助功能权限，状态会自动刷新；系统要求重开时，退出并打开同一位置的 App。
- 没有检测到按钮：确认设备报告额外鼠标按钮，在录制器测试身份。厂商工具把按钮改成键盘事件或合并编号时，App 无法恢复原始身份。超时不等于设备不支持。
- 服务异常：检查 App 和需要的映射已启用，在“设置 → 运行状态”点“重新尝试”。失效时先在“设置 → 帮助”复制诊断，再重试，以保留故障前状态。
- 启动锁不可用：检查个人资源库是否可写；不要删除运行中实例的锁文件。设备重连恢复有次数上限，仍失败时可重试。
- 报告问题：在帮助页预览诊断后复制或导出，提交 [GitHub Issue](https://github.com/double-u-zw/MacMouseGesture/issues)，注明系统、鼠标型号、连接方式及复现步骤。勿提交序列号、私人路径或未经检查的诊断。

输入计数、运行状态、probe 及事件提交成功均不能证明系统动画或目标应用已响应。升级 macOS 后失效时，可先停用并反馈；不要重置 TCC 数据库或降低安全设置。

## 卸载

1. 在设置中关闭“登录时启动”，并按需在“系统设置 → 通用 → 登录项”确认。
2. 退出所有 MacMouseGesture 实例，将 App 移到废纸篓；没有后台 helper 或 daemon 需要卸载。
3. 如需清除设置，可在 `~/Library/Preferences/` 删除 `io.github.double-u-zw.macmousegesture.plist`；使用过旧版时还可能有 `local.macmousegesture.poc.plist`。macOS 可能缓存偏好，退出登录后再确认。
4. 所有实例退出后，可清除 `~/Library/Application Support/local.macmousegesture.poc/` 的运行锁；自行删除保存的诊断，并在系统设置管理辅助功能/输入监控授权。

可选清理不属于正常卸载的必需步骤。隐私说明见根目录 [PRIVACY.md](../PRIVACY.md)。
