## 实际界面

- 主界面仍为“鼠标输入 / 操作方式 / 执行动作”三列。输入完整显示修饰键；普通动作有可见选择器，键盘动作显示“键盘快捷键 · ⌘T”等实际组合。
- 所有按钮共用添加、编辑流程。三个表单区与主表三列对应，使用原有鼠标输入和快捷键录制器。弹窗保存才应用；取消不写入。主表普通动作选择器直接应用选择。
- 行菜单包含编辑、停用或启用、删除。停用后变灰并显示“已停用”；删除需确认，并提供本次会话撤销。重复输入及操作方式会显示现有动作与启用状态，阻止保存，并可转入编辑现有映射。
- 连续拖动分组显示“按住拖动 → 触控板式手势 → 设置”。详情显示真实四方向记录和各方向状态，缺失方向保持缺省，只有勾选并保存才创建记录。固定手势动作不可任意替换。
- 全局参数明确说明影响所有手势按钮，并列出当前按钮。反转选项同步更新四方向效果说明；恢复默认只改全局参数草稿。
- 设置为次级入口。运行状态、权限检查、安装位置各保留一个入口；帮助和关于位于设置中。

## 配置边界

复用既有配置保存与 adapter API。没有修改 MappingStore、配置格式、adapter、PressClaim、录制器实现、动作执行器、输入运行时或连续手势核心，没有增加监听器、动作、触发方式、App Profile 或设备配置。

展示分组不写配置，不合并或重建底层记录。编辑现有手势组的输入保留原 ID、各方向启停和全局参数；全局参数单独保存不会把旧配置提前转换为受管理的拖动映射。配置文档继续使用 v4。

显式停用整个手势组时，本次会话记住原方向状态。退出后不会新增偏好元数据；再次启用时进入详情选择方向，避免自动启用原来停用的方向。显式确认删除手势组会删除该组现有方向记录，撤销恢复原 ID 和状态；如果输入已有新映射，撤销不会覆盖它。撤销仅在当前会话有效。
