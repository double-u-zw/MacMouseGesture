## 最小人工检查

1. 核对实际包版本、运行路径、权限和原设置；两颗侧键各四方向，停顿/继续/反向/松手，确认无额外短按。
2. 验证短按/长按/Wheel 互斥、释放后无残留、录制不执行已有映射；重复、禁用、删除、取消编辑及重启持久化。
3. 断连/重连、睡眠唤醒、权限撤销/恢复、多副本互斥及登录启动；失败先复制诊断，再重试。
4. 对目标动作观察真实应用响应；计数/API 结果不能代替画面。松手后 began 应等于 ended+cancelled，open=0，序列/投递错误为 0。
5. 性能采样需同一时间窗记录输入计数和 CPU，区分无输入/普通移动/手势；RSS 看多组趋势，缺失进程不能算 0%通过。

诊断与反馈操作见[安装与排错](INSTALL.md)。每次新增结论注明版本、系统、设备和实际场景，未测事项保留未测状态。
