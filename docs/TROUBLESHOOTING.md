# 权限与排错

- **没有菜单栏图标**：检查是否已退出，或 macOS 阻止了打开；遵循安装指南。若另一副本已运行，新副本会激活旧实例或退出。
- **需要授权 / 需要重新授权**：在系统设置 → 隐私与安全性 → 辅助功能启用当前 MacMouseGesture。App 每秒刷新状态；撤销后停止手势并等待重新授权。若系统要求重开，退出再打开同一安装位置的 App。
- **输入监控未授权**：它用于可选 HID 观察，不是当前辅助功能事件路径的硬性启动门槛。可先测试鼠标；最小权限组合的干净用户验收尚待完成。
- **没有检测到侧键**：确认鼠标具有额外侧键、配置中已启用对应侧键并尝试其他按键。超时不是设备不支持的结论。可在设置 → 通用重开首次设置与手势测试。
- **停用或引擎异常**：先启用 App 和至少一种手势，再在诊断页点“重新启动手势引擎”。仍失败请复制诊断。输入计数只证明捕获到输入，不证明系统动画正常。
- **无法启动（用户级锁）**：确认个人资源库可写；不要删除运行中的锁文件，也无需清理 App 父目录的历史 poc.lock。
- **报告问题**：菜单栏 → 诊断 → 展开高级诊断预览 → 复制诊断信息，按 Issue 模板描述复现步骤。即使已脱敏也请检查内容，勿提交私人路径、序列号或密码。

不重置系统权限数据库，不自动修改安全机制。升级 macOS 后若失效，请停用并报告系统版本。
