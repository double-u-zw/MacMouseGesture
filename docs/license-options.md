# 项目许可证候选（待决定）

No project-wide license yet. 先关闭 MMF 衍生范围、Apple 头文件来源及预期分发权利，再由用户决定是否商业化、是否允许第三方 fork/再分发。不能用自选许可证覆盖第三方限制。

| 候选 | 大致取向 | 决策点 |
|---|---|---|
| MIT | 宽松使用、修改、商业使用和再分发，保留声明 | 只有对可授权部分具备权利且第三方条件兼容时才可采用 |
| Apache-2.0 | 宽松授权，带明确专利许可/终止条款及通知要求 | 比 MIT 更具体；第三方兼容性仍需复核 |
| Source available / proprietary | 可提供查看源码的条件，同时保留再分发/商业化限制 | 需明确写授权条款；“源码可见”本身不是开放源代码许可 |

参考原文：[MIT](https://opensource.org/license/mit)、[Apache 2.0](https://www.apache.org/licenses/LICENSE-2.0)。此表是供选择的概要，不是针对本项目已完成的法律兼容结论。
