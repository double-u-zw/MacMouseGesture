# 鼠标侧键短按动作

侧键 4 对应 CG 按钮编号 3，侧键 5 对应编号 4。两颗侧键的短按动作默认均为“无操作”。在设置页“侧键短按动作”中分别选择动作；下方仍保留现有四方向手势设置。关闭某颗侧键会同时停止拦截它的短按和拖动；停用 App 或所有手势时服务仍按原有规则停止。

## 输入与清理

`SideButtonClickTracker` 只观察现有 `GestureMachine`，不累积另一套鼠标位移、不增加另一套阈值、不改变 120 Hz 调度、指针冻结、速度、方向反转或结束逻辑。

- 配置按钮按下：独立进入 `pendingClick`。
- 累计位移 `hypot(totalX, totalY) >= machine.config.deadZone`，或现有状态已锁定轴：所有当前持有按钮变为 `gestureStarted`，之后反向回到起点也不会恢复短按资格。
- 松开：只有仍为 `pendingClick` 的按钮执行配置动作；无对应按下的松开和重复松开均无动作。
- 两键重叠期间进入手势：两颗均取消短按资格；新加入已开始手势的按钮同样无短按资格。
- Escape、事件 tap 中断/恢复、设备移除、权限丢失、服务重启/停用、休眠、会话失活、退出：清空待点击状态。设置 App 失焦也清空待点击状态，后台四方向手势服务继续运行。

原有 `Sources/GestureCore/GestureMachine.swift`、`VerticalGestureTracker.swift`、原生 Bridge 均未修改。`GestureEngine.swift` 仅增加短按观察、动作执行与清理接入。

## 动作与限制

| 动作 | 实现 |
|---|---|
| 无操作 | 不注入任何输入 |
| 显示桌面 | 读取系统已配置快捷键；没有记录时尝试 F11 |
| 调度中心（Mission Control） | 复用现有 VerticalGestureTracker 和 sendVertical |
| 应用 Exposé | 复用同一纵向后端，使用向下动作 |
| 启动台（Launchpad） | 读取系统已配置快捷键；没有记录时尝试 F4 |
| 最小化窗口 | ⌘M |
| 全屏 / 退出全屏 | ⌃⌘F |
| 锁定屏幕 | ⌃⌘Q |
| 播放 / 暂停 | 配对媒体键事件 |
| 返回 / 前进 | ⌘[ / ⌘] |
| 自定义键盘快捷键 | 配对 keyCode 与 modifierFlags 键盘事件 |

显示桌面和启动台依赖系统快捷键设置；已禁用或无效的显式系统绑定安全失败，不修改系统偏好。F4 在不同系统/键盘上可能未绑定到启动台，必要时先在系统设置配置其快捷键。窗口、导航动作依赖前台 App 对标准快捷键的支持；媒体事件由系统选择接收者。输出成功只表示已提交事件，不代表 Dock 或目标 App 一定响应。调度中心/应用 Exposé 短按复用已有私有交互后端，其快速完整序列仍需真机验收。

自定义界面支持普通按键及 Command、Option、Control、Shift，多修饰键组合、重新录制、清除、取消。只按修饰键不会形成有效记录。录制时拦截本 App 的按键，防止 ⌘W、⌘Q 等先执行菜单命令；系统全局快捷键可能仍被 macOS 优先处理。

## 保存

继续使用 `ConfigStore.key = gesture.configuration.v1` 的本机 UserDefaults 字典：

- `button4ClickAction`、`button5ClickAction` 分别保存动作 rawValue。
- 自定义快捷键嵌套保存数值 `keyCode`、`modifierFlags`，显示字符串由当前键盘布局生成。
- 缺失字段、未知 action 或无效自定义快捷键安全降级为无操作；原有配置字段和迁移域不变。
- “清除”后保存会移除快捷键并将该按钮置为无操作；“取消”不更新配置。

## 真机验收

1. 使用本地开发构建启动 App，确认辅助功能权限和两颗侧键开启。首先保持两颗均为无操作，回归左右 Spaces、上拖调度中心、下拖应用 Exposé，以及停顿、继续、反转、松开收尾。
2. 设置侧键 4 为显示桌面，侧键 5 为调度中心。分别点击，各自只执行一次；按下时不动作，松开时执行。带小于当前触发距离的抖动重复点击。
3. 分别按住两颗侧键，在四个方向越过触发距离再松开；只能出现拖动手势，不能再显示桌面或触发另一轮调度中心。越阈值后反向回到起点再松开也不得短按。
4. 越阈值后按 Escape、手动停止、退出、切换设置 App 焦点、休眠/唤醒或断开鼠标；旧按钮松开不能产生短按。恢复后新按下/松开正常。
5. 每颗快速点击 20 次，再交替点击；重叠按下两键并拖动，尝试两种松开顺序。确认无状态残留、无按钮配置串用、无额外短按。
6. 录入 ⌘W、⌘T、⇧⌘4、⌃⌘Q，先确认显示与保存的配置，再在相应目标 App 中验证。测试纯修饰键不被记录，重新录制、取消不保存、清除后保存为无操作。
7. 重启 App，确认两键动作及快捷键仍在。逐项验证最小化、全屏、返回/前进、播放/暂停、启动台、锁屏；锁屏及关闭窗口快捷键请最后测试。
8. 修改系统显示桌面/启动台快捷键后复测；禁用绑定时应安全无动作。在多显示器、全屏窗口场景回归已有连续手势。

自动化 PASS 不替代以上真实鼠标与 Dock 响应验收。
